Guia de Administracion de Sistemas

Bienvenido a esta guia basica sobre administracion de sistemas informaticos en red

1. Instalacion del sistema operativo

Primero, se debe elegir el sistema operativo adecuado segun las necesidades del entorno

1.1 Requisitos previos

Verifica el hardware la compativilidad y realiza una copia de seguridad

1.2 Proceso de instalacion.

Utiliza un medio de instalacion (USB, DVD) y sigue los pasos del asistente

2. Configuracion de red

Una vez instalado el sistema, se debe configurar la red para permitir la conectividad

2.1 Direccion IP y DNS

Configura una IP estatica o dinamica y define los ervidores DNS

2.2 Pruebas de conectividad

Usa comandos como ping o traceroute para verificar la conexion
